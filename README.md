# マインドマップ

余白ノート・お絵かきツールと同じく、GitHub Pages に公開して PC / iPad のホーム画面から使う PWA です。
ローカルで試すだけなら `index.html` をブラウザで直接開いても動きます (その場合クラウド同期は使えません)。

## ファイル構成

- `index.html` 画面と CSS
- `app.js` 本体 (マップ編集、手書き、保存)
- `cloud.mjs` クラウド同期の配線 (ログイン画面、変更の検出、Service Worker)
- `sync.mjs` Firebase 接続と同期エンジン (余白ノートの sync.mjs を元にマップ用に調整)
- `manifest.webmanifest` / `sw.js` / `icon.svg` PWA 用

## 公開 (GitHub Pages)

余白ノートと同じ「main ブランチをそのまま公開」方式です。ビルドはありません。

1. GitHub で公開リポジトリ `kusimaru/mindmap-app` を作る (README などは追加しない)
2. このフォルダから `git push -u origin main`
3. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして保存
4. 数分後に https://kusimaru.github.io/mindmap-app/ で開ける。iPad は Safari の共有 →「ホーム画面に追加」、PC は Edge / Chrome のアドレスバーの「アプリをインストール」

以後は main に push するだけで更新され、開いているアプリも次回起動時に新しい版になります (`sw.js` の `CACHE` 名は変えなくてよい)。

## クラウド同期

- 左下の「クラウド同期」を開き、余白ノートと同じメールアドレス / パスワードでログインすると、他の端末と自動で同期します。
- 保存先は余白ノートと同じ Firebase プロジェクトの `users/{uid}/mindmaps/{mapId}` と `users/{uid}/meta/mindmap` です。Firestore のルールが `users/{uid}` 配下を丸ごと許可していない場合は「同期エラー」になるので、ルールに `mindmaps` と `meta/mindmap` を追加してください。
- 同期の単位はマップ 1 件で、新しい方 (updatedAt) が勝ちます。カテゴリの一覧は別の meta ドキュメントで同期します。
- ログアウトしてもこの端末のマップは残ります。

## できること
- カテゴリを作ってマップを分類 (追加 / 名前変更はダブルクリック / 削除)
- 複数マップの管理 (新規 / 複製 / 削除 / タイトル検索 / カテゴリ移動)
- マインドマップ編集: Tab 子追加、Enter 兄弟追加、Delete 削除、F2 または ダブルクリックで編集、Space 折りたたみ、矢印キーで移動、Alt+↑↓ で並べ替え、右クリックメニュー、選択ノード横の「＋」で子追加
- 選択ノード横の「−」で削除 (複数選択中はまとめて削除)。「＋」はホバーしただけでも出る
- 選択すると Miro 風のツールバーがノードの上に出る: 形 (なし / 丸枠 / 角丸 / 四角)、色と線 (18 色 + 実線 / 破線 / 点線、自動で枝の色を引き継ぐ)、太字、複製、削除、その他メニュー。複数選択中は全部に適用
- 子を持つノードは枝の付け根に○が出て、クリックで折りたたみ。畳むと子の数のバッジになる
- 新しいノードは空で作られ、「入力してください」のプレースホルダー表示 (Miro と同じ)
- ノードのドラッグ: 空いている場所に落とすとその位置に移動 (枝ごと)。ルートを動かすと全体が動く。別のノードに重ねると、外側なら「子」、テキストの上下なら「兄弟 (前/後)」として付け替え。ルートに重ねると左右どちらに置くかを決められる
- 親より反対側に動かすと枝の向きが自動で切り替わる (ルート直下のトピックは左右の側も切り替わる)
- 文字入力は Miro と同じく枝の線の上でそのまま打つ。打つたびにノード幅と枝が伸びる。Esc で取り消し
- 「整列」で手で動かした位置をすべて自動配置に戻す
- 複数選択: 背景を左ドラッグで範囲選択、Ctrl / Shift + クリックで追加・解除、Ctrl+A で全選択。複数選択のまま削除・ドラッグ移動ができる
- 手書き: 左のパレットで「ペン」を選び、キャンバス上をドラッグすると線が描ける (8 色 × 3 太さ: 1 / 2 / 4px、既定は細)。「消しゴム」で線をなぞると消える。Esc で選択ツールに戻る。手書きはマップと一緒に保存され、拡大縮小・画面移動にも追従する
- 液タブ / ペンタブレット対応: 入力はポインターイベントで受けるので、ペンでもマウスと同じように描ける。ペンの消しゴム側 (テール) はどのツールでも消しゴムとして働く
- 手書き線の選択: 選択ツールで線をクリック (Ctrl+クリックで追加、範囲選択も可)。ドラッグで移動、Delete で削除、上に出るバーで色と太さを変更。ノードと一緒に選んでまとめて動かせる
- 戻す / やり直し: 左のパレットのボタン (Ctrl+Z / Ctrl+Y)。ノード操作と手書きの両方が対象
- iPad: 1 本指で背景をドラッグすると画面移動、2 本指でピンチ拡大縮小。ペン / 消しゴムのときは Apple Pencil で描き、指は画面移動とピンチ専用 (手のひらが触れても線は乱れない)
- 画面操作 (Miro のボードで確認した挙動に合わせた): ホイールで拡大縮小、Shift + ホイールで横移動、Space + ドラッグ または 中ボタンドラッグで画面移動。右下に 全体表示 / − / % / ＋ / ? のズームバー
- 元に戻す / やり直す (Ctrl+Z / Ctrl+Y)
- ドラッグで画面移動、ホイールで拡大縮小、全体表示 (Ctrl+0)
- 自動保存 (ブラウザの localStorage)
- 全データの JSON 保存 / 読込 (置き換え or 追加)
- マップを Markdown アウトラインとして出力

## データ形式 (JSON)
```json
{
  "version": 1,
  "categories": [{ "id": "...", "name": "仕事", "color": "#3b82f6" }],
  "maps": [{
    "id": "...", "categoryId": "...", "title": "タイトル", "updatedAt": 0,
    "root": { "id": "...", "text": "中心", "collapsed": false,
              "children": [{ "id": "...", "text": "枝", "side": "R", "children": [] }] }
  }]
}
```

`side` はルート直下の子だけが持ち、`R` (右) / `L` (左) で表示側を決める。
`dx` / `dy` は手で動かしたときの自動配置からのずれ (枝ごとに継承)。無いときは自動配置のまま。`dx` は「親から外側へ」の向き (左側の枝では画面上は左向き) なので、枝が反対側に切り替わっても子の並びが鏡写しで保たれる。`version: 2` からこの意味 (v1 のデータは読み込み時に変換)。
`shape` (pill / round / rect)、`color` (#rrggbb)、`bold` (true)、`line` (dashed / dotted) は任意。`color` と `line` は子孫に引き継がれる。
マップの `strokes` は手書き線の配列: `{ id, color, width, points: [[x, y], ...] }` (座標はマップ座標)。
