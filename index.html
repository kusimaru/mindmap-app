📤 余白ノートへ送る 未設定

「余白ノートへ送る」ボタンで、今見えている範囲のキャプチャ (PNG) を余白ノートの「データ受け取り › マインドマップ」に届けます。iPad でも届けるには、余白ノートと同じ GitHub の設定を入れてください。

☁ クラウド同期 オフ

余白ノートと同じメールアドレスとパスワードでログインすると、他の端末と自動で同期します。

操作ヘルプ
Tab 子を追加　Enter 兄弟を追加　Delete 削除　Ctrl+D 複製　Ctrl+B 太字
F2 / ダブルクリック 編集　Space 折りたたみ　枝の付け根の○でも開閉
↑↓←→ 移動　Alt+↑↓ 並べ替え　右クリック メニュー
ノードをドラッグ 移動 (他のノードに重ねると親の変更 / 並べ替え)
背景ドラッグ 範囲選択　Ctrl+クリック 追加選択　Ctrl+A 全選択
ホイール 拡大縮小　Shift+ホイール 横移動　Space+ドラッグ / 中ボタン 画面移動
左のパレット: ペンで手書き、消しゴムでなぞって消す、Esc で選択に戻る
